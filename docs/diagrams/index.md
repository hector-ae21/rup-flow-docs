# Diagram catalogue

rup-flow draws fourteen kinds of diagram from one example project, an online shop. Three are free and cover the first disciplines; the other eleven are part of rup-flow Pro. Every image follows the theme of this page. The catalogue is the one the CLI prints with `RUP editions`.
