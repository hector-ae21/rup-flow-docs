# rup-flow Pro

The free edition gets you through requirements. Pro takes the same project the
rest of the way: models you can trust, code that traces back to them, and
documentation that stays honest as the code changes.

<div class="rup-callout" markdown>

**Pro is a separate product.** It is not a fork: it is the free skill with an
extension laid over it, so everything you learned in the free edition applies.
It is described here at feature level; the free documentation covers the shared
parts completely.

</div>

## What Pro adds

<div class="rup-grid" markdown>

<div class="rup-card rup-card--linked" markdown>

### The complete documentation set

The ranked domain model, entity lifecycles, use-case diagrams, wireframes,
analysis, design, implementation and quality artifacts, linked by one
navigation table per use case.

[See the set](documentation-set.md)

</div>

<div class="rup-card rup-card--linked" markdown>

### Code in both directions

Reverse engineering with evidence, code generation with trace links, drift
detection and audits.

[See the workflows](code.md)

</div>

<div class="rup-card rup-card--linked" markdown>

### Themes, Mermaid and the explorer

Eight palettes or your own colors, Mermaid as a second language, PNG previews
and an interactive explorer.

[See the look](themes-and-explorer.md)

</div>

<div class="rup-card rup-card--linked" markdown>

### Packs, libraries and subagents

Stack packs, ready domain libraries and two subagents that generate and review
independently.

[See the extras](packs-and-agents.md)

</div>

## Is Pro for you?

| If you ... | Pro gives you |
| --- | --- |
| Document a system before building it | Every discipline in one consistent structure |
| Inherit code nobody documented | Documentation derived from the code, each claim cited with its location |
| Have docs and code that drift apart | A table of differences: model ahead, code ahead, conflict, dead |
| Need a deliverable for a course, a client or an audit | A complete, traceable, consistently styled set |
| Want the agent to build from reviewed models | Code, tests and `@rup` trace links generated from them |
