# rup-flow Pro

The free edition gets you through requirements. Pro takes the same project the rest
of the way: models you can trust, code that traces back to them, and documentation
that stays honest as the code changes.

!!! info "One skill, two editions"

    Pro is not a fork. It is the free skill with an extension laid over it, so
    everything you learned in the free edition applies, and every free page of this
    site still describes how Pro behaves. This section documents what Pro adds, in
    detail.

## Is Pro for you?

| If you ... | Pro gives you |
| --- | --- |
| Document a system before building it | Every discipline in one consistent structure |
| Inherit code nobody documented | Documentation derived from the code, each claim cited with its location |
| Have docs and code that drift apart | A table of differences: model ahead, code ahead, conflict, dead |
| Need a deliverable for a course, a client or an audit | A complete, traceable, consistently styled set |
| Want the agent to build from reviewed models | Code, tests and trace links generated from them |

## How Pro is versioned

Pro has its own version, `1.0.0` today, and always states the free version it
contains: `rup.mjs version` prints `rup-flow Pro 1.0.0 (built on rup-flow free 1.0.0)`.
Pages and rows of this site marked <span class="rup-pro-tag">Pro</span> say since
which Pro version they apply. See [Pro versions and compatibility](versions.md).
