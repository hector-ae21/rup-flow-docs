# Security policy

This repository holds documentation sources and tooling. It processes no user data and publishes no secrets.

## Reporting a vulnerability

Use GitHub private vulnerability reporting: **Security → Report a vulnerability** on this repository. It reaches the maintainer for the documentation and for the skill. Do not open a public issue for a vulnerability or an exposed credential.

## Scope

- Content that suggests an unsafe practice.
- A credential or private data committed by mistake.
- A vulnerability in the build or publication workflows.
- A vulnerability in the rup-flow skill or its packages.
